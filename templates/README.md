## Description

This is a research prototype of an explainable AI-powered Election Intelligence Platform designed for low-resource democracies. It supports:

- Logistics Risk Assessment
- Transparency / Anomaly Detection
- Misinformation Triage
- Human-in-the-loop review
- Audit Trail
- Basic Reports
